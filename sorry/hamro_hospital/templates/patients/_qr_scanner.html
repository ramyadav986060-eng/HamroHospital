{% comment %} Reusable "Scan Patient QR Code" widget. Drop this include on any Search Patient screen in any module: {% include 'patients/_qr_scanner.html' with target_prefix="id_" %} target_prefix must match the id="" prefix of your search input fields, e.g. if your form has , , then pass target_prefix="id_" (the default). Only the fields that exist on the page get filled - missing ones are skipped. On a successful scan this: 1. plays a confirmation beep 2. calls /patients/api/qr-lookup/?code=... 3. auto-fills #{{ prefix }}patient_code, #{{ prefix }}full_name, #{{ prefix }}phone_number, #{{ prefix }}age, #{{ prefix }}age_input, #{{ prefix }}gender, #{{ prefix }}qr_code (if present on the page) 4. fires a `tuh:patient-scanned` custom event with the patient JSON, so a module can hook extra logic (e.g. auto-submit the search). Hardware barcode scanners (USB/Bluetooth "keyboard wedge" scanners that read the Code128 barcode on the printed Patient Card) need no extra code here - they just type the patient_code into whichever text input is focused followed by Enter, which submits the surrounding search form exactly like a person typing it. Point staff at the existing "Patient ID / Search" field for that; this widget adds camera-based QR scanning on top. {% endcomment %}
